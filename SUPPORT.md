# Support

## Community support

Use GitHub Discussions or a GitHub issue for installation questions, bug reports,
and feature proposals. Include the Datalox version, Python version, operating
system, exact command, structured error code, and a minimal sanitized reproduction.

Community support is provided on a best-effort basis without a response-time SLA.

## Security and sensitive data

Do not include credentials, provider response bodies, tenant identifiers, run
exports, or private behavior evidence in a public issue. Report vulnerabilities
through the private process in [`SECURITY.md`](SECURITY.md).

## Commercial support

Commercial support, private provider packs, and partner behavior-grounding work
are outside the community support channel. Use the contact method published by
the repository owner rather than opening a public issue containing operational
details.
