# Code of Conduct

## Our standard

We are committed to a respectful, harassment-free project community. Be direct
about technical disagreements while remaining considerate of the people involved.
Examples of welcome behavior include giving actionable feedback, acknowledging
uncertainty, crediting sources, and protecting sensitive provider or user data.

Harassment, threats, discriminatory language, deliberate exposure of private
information, and sustained disruption are not acceptable.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently
restrict participation when behavior is harmful to the project or community.
Enforcement decisions should be proportionate, documented privately, and avoid
unnecessary disclosure about affected people.

Report conduct concerns privately to a maintainer using the repository owner's
published contact method. Do not use a public issue when a report contains
personal or sensitive information.

This policy applies in project repositories, discussions, issue trackers, review
threads, and project-related public events.
